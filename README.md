# Помогариум — лендинг репетиторского центра

Одностраничный сайт: подбор онлайн-репетиторов, карусели преподавателей и отзывов,
форма заявки с рассылкой в Telegram-бота и резервной копией в CSV.

**Стек:** React 18 + Vite + TypeScript (клиент) · Node 20 + Express + TypeScript (сервер) · npm workspaces.

---

## Требования

- **Node.js 20 LTS** (или новее). Проверка: `node -v`.
- npm 10+ (идёт с Node).

> ⚠️ Путь к проекту — только латиница, без пробелов и кириллицы
> (иначе падают нативные пакеты `esbuild` / `rollup` под Windows).

---

## Установка

```bash
npm install          # ставит зависимости всех воркспейсов
cp server/.env.example server/.env   # (Windows: copy server\.env.example server\.env)
```

## Разработка

```bash
npm run dev
```

- клиент — http://localhost:5173 (Vite, HMR)
- сервер — http://localhost:3001 (API, автоперезапуск)
- запросы `/api/*` с клиента проксируются на сервер автоматически

## Прод-сборка

```bash
npm run build        # client → client/dist, server → server/dist
npm start            # поднимает Express, он же раздаёт client/dist на PORT (3001)
```

Проверка типов (необязательно, отдельно от сборки):

```bash
npm run typecheck --workspace client
```

## Форма заявки: куда падают заявки

Логика в [`server/src/leads.ts`](server/src/leads.ts) и [`server/src/telegram.ts`](server/src/telegram.ts).
Каждая заявка идёт по двум каналам:

| Канал | Что делает |
|---|---|
| **Telegram-бот** | рассылает заявку сообщением **всем**, кто отправил боту `/start` |
| **CSV** | всегда дописывает строку в `server/data/leads.csv` (Excel, разделитель `;`) — резервная копия |

### Настройка Telegram-бота

1. [@BotFather](https://t.me/BotFather) → `/newbot` → получить токен (или `/token` для существующего).
   Текущий бот проекта — **@Violetta\_Zayavki\_bot**, токен уже в `server/.env`.
2. В `server/.env`:
   ```
   TELEGRAM_BOT_TOKEN=123456:AA...
   TELEGRAM_SUBSCRIBE_CODE=          # необязательно, см. ниже
   ```
3. Запустить сервер (`npm run dev` или `npm start`) — бот поднимается автоматически
   (long-polling, вебхук/белый IP не нужны).
4. Каждый, кому нужны заявки, открывает бота и жмёт **/start** (или пишет «старт»).
   Список подписчиков хранится в `server/data/subscribers.json`.
   - `/stop` — отписаться, `/status` — проверить.
   - Если подписчик заблокирует бота — он автоматически удаляется из рассылки.

**Ограничение доступа.** По умолчанию подписаться может любой, кто знает ссылку на
бота (и увидит телефоны клиентов). Чтобы закрыть — задайте
`TELEGRAM_SUBSCRIBE_CODE=какой-то-секрет`; тогда подписка только командой
`/start какой-то-секрет`.

> Если бот когда-нибудь скомпрометирован — в [@BotFather](https://t.me/BotFather)
> сделайте `/revoke` и обновите токен в `server/.env`.

## Антиспам

- honeypot-поле `company` (скрыто от людей);
- «time-trap» — заявки быстрее 1.5 с после загрузки формы игнорируются;
- rate-limit: не более 8 заявок с IP за 10 минут.

## Про флаг `--no-opt` в скриптах

Скрипты запускают Node как `node --no-opt …`. Это отключает оптимизирующий
JIT-компилятор V8. Причина: на машине разработки корпоративный антивирус/EDR
роняет `node.exe` (ошибка `0xC0000005`) при JIT-компиляции — падают `vite`, `tsc`, `tsx`.
`--no-opt` это обходит ценой небольшой потери скорости (для сборки и лёгкого
Express-сервера незаметно).

- На чистой машине или Linux-сервере флаг безвреден, можно оставить.
- Для нагруженного прод-сервера на Linux — убрать `--no-opt` из `server` `start`
  (в `Dockerfile` его и так нет).
- Правильное «лечение» на dev-машине: добавить в исключения антивируса
  `C:\Program Files\nodejs\node.exe` и папку проекта, либо работать из WSL2 —
  тогда флаг тоже можно убрать.

> ⚠️ `NODE_OPTIONS=--no-opt` **не работает** (Node запрещает этот флаг в переменной),
> поэтому он прописан прямо в командах скриптов.
